# Marquee – downloads

Download files for Marquee. The code isn't here.

- **Windows (beta):** [Marquee.exe](https://github.com/oscardante/marquee-downloads/releases/latest/download/Marquee.exe)
- **Mac:** [Marquee.dmg](https://marquee-updates.pages.dev/Marquee.dmg)

Marquee updates itself after that. Windows updates are only installed when they carry Marquee's signature.
